Gemini Chatbot Single Page Application Documentation

Project Overview:
This is a Single Page Application (SPA) built with vanilla HTML, CSS, and JavaScript that integrates Google's Gemini API to create a simple chatbot interface. Users can type messages, send them, and receive responses from the Gemini AI model.

3. script.js - JavaScript for handling user input and API integration.

const API_KEY = 'YOUR_API_KEY'; // Replace with your actual Gemini API key
const API_URL = `https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent?key=${API_KEY}`;

const chatMessages = document.getElementById('chat-messages');
const userInput = document.getElementById('user-input');
const sendButton = document.getElementById('send-button');

sendButton.addEventListener('click', sendMessage);
userInput.addEventListener('keypress', (e) => {
    if (e.key === 'Enter') {
        sendMessage();
    }
});

function sendMessage() {
    const message = userInput.value.trim();
    if (message === '') return;

    // Display user message
    displayMessage(message, 'user');
    userInput.value = '';

    // Send to Gemini API
    fetchGeminiResponse(message);
}

function displayMessage(text, sender) {
    const messageDiv = document.createElement('div');
    messageDiv.classList.add('message', sender + '-message');
    messageDiv.textContent = text;
    chatMessages.appendChild(messageDiv);
    chatMessages.scrollTop = chatMessages.scrollHeight;
}

async function fetchGeminiResponse(prompt) {
    try {
        const response = await fetch(API_URL, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
            },
            body: JSON.stringify({
                contents: [{
                    parts: [{
                        text: prompt
                    }]
                }]
            })
        });

        if (!response.ok) {
            throw new Error('API request failed');
        }

        const data = await response.json();
        const botResponse = data.candidates[0].content.parts[0].text;
        displayMessage(botResponse, 'bot');
    } catch (error) {
        console.error('Error:', error);
        displayMessage('Sorry, I encountered an error. Please try again.', 'bot');
    }
}

Output:
The application features a modern chat interface with a header displaying the title, a dark mode toggle button (moon/sun emoji), and a clear chat button (trash emoji). The container is semi-transparent white on an animated gradient purple background with a subtle dotted pattern, interactive animated floating particles that scale and brighten on hover, rising bubbles that float upwards, and a neural network visualization with pulsing nodes and glowing connections representing AI processing. On load, a welcome message from the bot appears. Messages include user/bot avatars (👤/🤖), text bubbles, and timestamps. User messages appear in gradient purple bubbles on the right with slide-in animations, bot responses in light gray bubbles on the left. A typing indicator with animated bouncing dots shows while waiting for the bot's response. Messages slide in smoothly, the send button has a rocket emoji with hover and active effects, and buttons scale on hover. A scroll-to-bottom button appears when scrolled up. The input auto-focuses on load, and the UI is responsive with smooth scrolling. Dark mode switches to a dark theme with animated blue-gray gradients, inverted colors, a faint dotted pattern, dimmed floating particles, dimmed bubbles, and dimmed neural network elements.
